# Jewish Chronology Lab / Лаборатория еврейской хронологии

Отдельное статическое исследовательское приложение по [jewTeX #23](https://github.com/Ishayahu/jewTeX/issues/23).

**Демо после включения GitHub Pages:** https://ishayahu.github.io/jewish-chrono/

## Возможности
- Выбор конкурирующих датировок и собственных годов АМ.
- Независимые гипотезы-связи между событиями; возраст 47 лет — отдельное включаемое свидетельство.
- Строгий режим отклоняет несовместимые варианты; исследовательский режим показывает величину конфликта и происхождение расчёта.
- Временная шкала, таблица событий и ссылки на канонические XML-источники в `Ishayahu/jewTeX_TEXTS_DB`.
- Публичный каталог свидетельств и правил в `data/*.json`; личные сценарии — в localStorage, с экспортом/импортом JSON.

## Запуск локально
Нужен обычный статический HTTP-сервер (нельзя запускать напрямую через `file://`, потому что данные подгружаются через `fetch`):

```sh
python3 -m http.server 8000
# http://localhost:8000/
node --test tests/*.test.mjs
```

Зависимостей, серверного приложения и секретов нет.

## GitHub Pages
Перейдите в **Settings → Pages → Build and deployment → Source: GitHub Actions**. Коммит в ветку `main` запускает `.github/workflows/pages.yml` и публикует корень репозитория. До завершения Actions адрес сайта может возвращать 404.

## Методологические границы
Согласованность чисел **не доказывает** достоверность датировки или отождествления исторических лиц. Сообщение источника, гипотеза исследователя и арифметически производная дата различаются по типу и статусу. Конкретные годы 3927/3948 — вычисленные иллюстрации, не даты, приписанные «Цемах Давид». Сведения с пометкой о необходимости проверки не выдаются за проверенные. Модель оперирует целыми годами АМ (в том числе тестовыми отрицательными значениями); точные дни рождения и конвертация календарей не реализованы.

Исходная задача и обсуждение источников: [jewTeX #23](https://github.com/Ishayahu/jewTeX/issues/23).
